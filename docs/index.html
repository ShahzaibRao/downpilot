FAQ

Common questions.

Is it free?

Yes! DownPilot is MIT-licensed open source. Free forever for local use.

Windows shows a SmartScreen warning?

The app is unsigned (v1). Click "More info" → "Run anyway". This is expected and safe — the code is open source.

Some videos fail to download?

Usually a login wall. Add cookies in Settings → Cookie profiles. Or enable Smart Mode with a proxy.

Will it re-download deleted files?

Never! Prospect mode tracks by content ID. Once downloaded, it's marked seen forever — even if you delete the file.

How do updates work?

The app checks GitHub Releases on startup and daily. Updates download in background; you'll be asked before restarting.
